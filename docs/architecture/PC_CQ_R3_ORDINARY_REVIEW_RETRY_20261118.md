# R3 ordinary review save retry and rollback

Ordinary ReviewWindow explicit Save could acknowledge a queued page after its original rows disappeared even though live entries or Tk input remained. An unresolved prior write could also reach the queued-page clean path. On idle pages a partially rebound simplified column could be skipped during capture while the paired writer still committed an older cache. Explicit Save and autosave now share the original and simplified editor ownership checks. An unresolved write is refused before bridging text or claiming a page. A verified paired save or an owned clean no-op clears the pending status.

The ordinary rollback guard compared only the PDIC file and original-word widgets. A simplified-only edit, replaced simplified editor or surviving recovery journal could therefore leave visible input out of sync with restored cache state. The guard now requires exact unchanged PDIC and simplified bytes, no remaining journal and unchanged identities and values for both editor columns before restoring the in-memory snapshot. It preserves the original writer error and unresolved state when readback fails, the journal remains or newer edits appeared. A known pre-publication failure can be retried after both columns bind to the current page entries.
